# Changelog

All notable changes to Hey Frank AI Assistant will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive test suite with 225+ automated tests
- Manual testing documentation and templates
- Message history visibility fix - always show conversation icon
- Smart conversation list display
- Professional Git workflow structure

### Changed
- Improved conversation management UI
- Enhanced message history component

## [0.1.8] - 2024-12-20

### Added
- Complete overlay transparency for WebView2 windows
- Persistent toggle window that survives focus loss
- Compact settings interface accessible from overlay
- Professional testing framework with Vitest
- SQLite database for conversation persistence
- Multi-provider AI support (OpenAI, Claude, Gemini, etc.)
- Real-time streaming AI responses
- Voice input with speech-to-text
- File attachment support with image uploads
- Screenshot capture functionality
- Global keyboard shortcuts
- System tray integration
- Auto-start on boot
- Dark/Light theme support
- Markdown rendering with code highlighting
- Conversation export to markdown
- System prompt management
- Response length customization
- Audio settings configuration

### Changed
- Improved window transparency implementation
- Enhanced focus loss handling
- Optimized database queries
- Refactored component library structure

### Fixed
- Window disappearing on focus loss (WS_EX_NOACTIVATE)
- Overlay transparency issues
- Conversation history visibility bug
- Database connection errors
- Theme switching glitches

## [0.1.7] - 2024-12-15

### Added
- Initial Tauri + React + TypeScript setup
- Basic AI integration
- Simple chat interface

### Changed
- Project structure improvements
- Code organization

## [0.1.6] - 2024-12-10

### Added
- Project initialization
